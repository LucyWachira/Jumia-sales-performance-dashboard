# Jumia Nigeria Sales Performance Dashboard

An end-to-end data analytics project transforming over 5,000 raw e-commerce transaction records from Jumia Nigeria into an interactive, insight-driven business dashboard.

![Jumia Sales Dashboard](dashboard.png)

---

## 📂 Workbook Architecture & Features
This project is organized across multiple dedicated worksheets to maintain a clean analytics workflow:

*   *Jumia Sales Dashboard (Main View):* The interactive executive interface featuring dynamic KPIs, revenue trend charts, regional profit margin comparisons, and interactive slicers for seamless filtering.
*   *Data Cleaning & Processing:* The backend data layer where raw fields were standardized. Leveraged advanced text functions (UPPER, TRIM, PROPER), logical cell references, and Power Query to handle missing entries and fix inconsistent Nigerian regional naming conventions.
*   *Pivot Tables & Analytics:* Dedicated analytical sheets utilizing PivotTables, SUMIFS, AVERAGEIFS, and calculated fields to aggregate data across top-selling categories and daily order volumes.

---

## 🛠️ Skills & Technical Functions Demonstrated
*   *Data Cleaning:* Duplicate removal, handling blank rows, text string manipulation, and currency standardization.
*   *Advanced Formulas:* VLOOKUP/XLOOKUP, IF statements, conditional aggregations (SUMIFS, COUNTIFS), and relative/absolute cell referencing.
*   *Data Visualization:* Interactive dashboards, conditional formatting, custom charting, and slicer connections.
